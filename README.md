# CampusConnect

CampusConnect is a campus-focused platform designed to help students
connect with classmates, discover campus activities, and access
important campus information.

## Project Overview

The CampusConnect case focuses on improving communication and
collaboration among students within a campus community.

## Features

- Student community
- Campus announcements
- Events and activities
- Student connections
- Campus information
